# Erector Design

矢崎化工の製品「[イレクター](https://www.yazaki.co.jp/products/erector/)」を使用した構造物の設計を行うWebアプリケーションです。

🔗 **デモ**: <https://erector-design.vercel.app>

## 📋 概要

イレクターの主要部品（パイプ・ジョイント）をリストから選択し、  
それらを組み合わせて構造物を設計することができます。  
各部品の組み合わせや座標を入力して必要な部品や数量、完成品の形状・動作を確認することができます。

## ✨ 主な機能

<!-- 各機能の説明を1〜2文ずつ書く。スクショはコメント位置に貼る -->

### 3Dリアルタイム編集

- カタログからパーツ（パイプ・ジョイント）を選択して配置
- ギズモによる移動・回転操作、接続関係の管理
<!-- スクショ: ギズモでパイプを操作している場面 -->

### 接続バリデーション

- 不正な接続をリアルタイム検出し、エラー一覧と3Dシーン上の矢印で表示
<!-- スクショ: エラーオーバーレイ表示 -->

### シミュレーションモード

- 可動ジョイント（回転・首振り・着脱）を動かして完成品の動作を確認
<!-- スクショ or GIF: 可動ジョイントを動かしている場面 -->

### 配置境界チェック

- 設置可能領域・除外領域を定義し、はみ出し/干渉を検出
<!-- スクショ: 境界ワイヤーフレームと違反バッジ -->

### 価格見積もり

- ジョイント単価とパイプのカッティングストック計算による部品コスト見積
<!-- スクショ: 見積ダイアログ -->

### その他

- undo/redo（Ctrl+Z / Ctrl+Y）
- デザインのJSON保存・読込
- モバイル対応（タッチ操作＋ボトムシートUI）

## 📖 使い方

<!-- 各ステップに1〜2文の説明を書く。詳細な操作説明が必要になったら docs/ に分離 -->

1. **パーツを選ぶ** — 左パネル（モバイルはパーツタブ）からパイプ・ジョイントを選択して追加
2. **組み立てる** — 3Dシーン上でギズモを使って配置し、ジョイントの穴にパイプを接続
3. **エラーを確認** — 画面下部（モバイルはエラータブ）で不正な接続をチェック
4. **動作を確認** — シミュレーションモードに切り替えて可動部を動かす
5. **見積・保存** — 見積ボタンで部品コストを確認、Downloadボタンで設計をJSON保存

## 🛠️ 技術スタック

- **フレームワーク**: [Nuxt.js](https://nuxt.com/)
- **言語**: TypeScript
- **3Dレンダリング**: [Three.js](https://threejs.org/)
- **Node.js**: v24
- **パッケージマネージャー**: pnpm

## 🚀 セットアップ

### 前提条件

- Node.js v24
- pnpm

### インストール手順

1. リポジトリをクローンします：

    ```bash
    git clone https://github.com/EwdErna/erector-design.git
    cd erector-design
    ```

2. 依存関係をインストールします：

    ```bash
    pnpm install
    ```

## 💻 開発

### 開発サーバーの起動

```bash
pnpm dev
```

開発サーバーが起動し、`http://localhost:3000` でアプリケーションにアクセスできます。

### ビルド

```bash
pnpm build
```

### プレビュー（本番環境での動作確認）

```bash
pnpm preview
```

## 📁 プロジェクト構成

```yml
erector-design/
- components/       # Vue コンポーネント
- composables/      # Vue コンポーザブル
- data/             # パーツ情報
- public/           # 公開ファイル
    - models/       # コンポーネント3Dモデル
- stores/           # Pinia ストア定義
- types/            # TypeScript 型定義
- utils/            # 計算ユーティリティ
- nuxt.config.ts    # Nuxt.js 設定
- package.json      # 依存関係とスクリプト
```
